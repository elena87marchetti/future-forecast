# Future Forecast

Gioco di ripasso di inglese per la terza media, pensato per prepararsi alla verifica sul futuro.

**Come si apre:** basta aprire `index.html` in un browser. Non serve installare niente. Se il repository ha GitHub Pages attivo, il gioco si apre anche dal link del sito.

## Contenuti

Nove tappe, una per pagina, con frasi pescate a caso a ogni partita:

1. Be going to (affermative, negative, domande e risposte brevi)
2. Pronomi relativi: who, which, where, when, whose
3. Will, won't, may / might (sure / not sure)
4. Domande e risposte brevi con will
5. Will o be going to?
6. First conditional
7. Verbi + -ing, to o forma base, più frasi personali
8. Lessico: i lavori (dall'italiano all'inglese)
9. Lessico: il meteo estremo (con un termine in più)

Le **schede riassuntive** di grammatica e vocabolario si aprono in qualsiasi momento con il pulsante *Schede*.

## Note

- I progressi (i "soli" guadagnati) restano salvati nel browser di chi gioca.
- I caratteri arrivano da Google Fonts. Senza connessione il gioco funziona comunque, con i caratteri di sistema.
